# Enterprise Workflow Management Platform

**Status: Scaffold only — features are not yet implemented.**

A planned full-stack workflow platform using Java 21, Spring Boot, React, TypeScript, and PostgreSQL. First milestone: project/task CRUD with persistence and tests. Authentication, collaboration, CI, and AWS deployment are later milestones.

See `docs/roadmap.md` for planned milestones and `docs/architecture.md` for the planned architecture.
